实际运行依赖
------------

  encos_usb_can 或 encos_usb_can_node → SerialCanTransport → USB‑CAN 模块 → CAN 总线
  USB‑CAN 命令行会话打开一个串口，键盘命令经 Protocol 编码发送，空闲时照常接收。
  收到的 CAN 帧 → encos_core::Protocol → 终端或 ROS 2 的原始帧和 MotorState
  现场授权后可读 ID 和参数，由 TransactionManager 匹配应答。
  record.launch.py 保存两个实际话题，encos_experiments 导出 CSV 并分析主机接收时序。

离线验证与保留 API
------------------

  C++ 协议、事务及安全用例和 Linux 伪终端测试无需连接 CAN。
  RunExperiment.action 与轨迹库保留。当前 USB 节点提供只读通信。
  历史阶段记录、旧安装产物和工具指南已移到工作区外的历史归档。
