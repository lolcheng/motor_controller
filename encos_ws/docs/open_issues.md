## P1 新增事项

| ID | 发现 | 处理 |
|---|---|---|
| P1-01 | ENCOS 报文没有事务序号，Linux vcan 上的局部测试不能证明真实电机响应寿命。 | 保留 P0 默认签名隔离。性能工具在专用虚拟总线上使用已成功且只发一帧的仿真约定，任何失败后结束本轮。使用前确认没有其它发送者或异常注入。实际硬件迟到上界待确认。 |
| P1-02 | SocketCAN 软件时间戳取自内核实时钟。vcan 反馈由同机另一 socket 发出，CAN_RAW 的本机标志意义不等同于当前 socket 自己回环。 | 禁止当前 socket 读回自己的发送。记录内核实时钟同时估计主机单调接收时间，大幅时钟跳变或缺少时间戳时降为未知来源。当前采样时间为主机接收，电机采样时刻未知。 |
| P1-03 | 宿主网络无创建接口权限，本机 vcan 模块可由内核使用。 | 自动验证在无 sudo 的隔离用户和网络命名空间进行。真实链路、采样点、BRS 电气层和硬件故障恢复仍未验证。 |
| P1-04 | 配置 0x02、0x0F 和 Kt EE 回复存在 P0 记载的歧义。 | 0x02 只记录模拟待切换模式，保持当前帧格式并且不生成假设回显。0x0F 回显独立的原值，写入后不推断查询 35 枚举。在已知 mode=0 的编组中验证 EE，其他布局待厂商确认。 |
