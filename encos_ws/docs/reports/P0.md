## 完成的功能

- **协议核心**。C++17 标准 ID 帧模型、经典 CAN 和 CAN FD+BRS 封装，以及逐位串行化。按第 7–11 章拆分管理、控制、配置、读回和各类反馈。严格核对长度、帧标志、枚举、有限数、整数可表示范围和符号。未知、冲突和非法帧保留来源、接收时间和原始数据。
- **运行时参数**。混控编码及类型 1 解码分别使用核验过的区间。类型 2/3 的缺失量为空，量测带主机单调时钟接收时间。相电流与力矩估算独立，后者仅在 Kt 有效且查询 35 确认未启用补偿时计算。
- **事务**。单个待决请求，匹配标准 ID、帧型、反馈类型、参数码和特殊应答。区分零点/ID 共用失败码、一般配置 ACK、特殊回显及两种抱闸反馈。处理 UUID 三帧的乱序、重复、冲突及缺失，匹配 Kt 组并核对设置回显。拒绝本机回环、来源未知帧、未发送时已接收帧和逾期帧。备有 500 ms 写入后的等待约束。
- **安全限制**。默认未授权，单一命令所有者，需独立人工授权只读和运动。运动前要求核验 ID、通信方式、软硬件版本、范围、Kt、补偿、非零超时、抱闸能力和停止策略。检查各反馈字段的独立新鲜度、命令新鲜度、运行时长、位置、速度、相电流、估算力矩、温度和增益，复核量化后的命令。故障进入锁存状态，重连与复位均要求重新核验。停止状态向上层报告，物理停止策略留待厂商及现场验证。
- **离线传输与构建**。Transport 抽象和有界 MockTransport 队列支持注入接收帧、逻辑断连、模拟回环及读取发送记录。核心可独立构建，Jazzy 的 ament 包导出同一个库。配置写入接口需要显式离线权限，P0 没有实际设备传输路径。

## 编译和测试记录

环境为 Ubuntu 24.04.4 LTS，GCC 13.3.0，CMake 3.28.3，已安装 ROS 2 Jazzy。以下命令在工作区执行。独立构建以 CMake 参数关闭 ament 查找。

```bash
bash scripts/run_offline_tests.sh

cmake -S src/encos_core -B build/p0-sanitize \
  -DCMAKE_DISABLE_FIND_PACKAGE_ament_cmake=ON -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_CXX_FLAGS='-fsanitize=address,undefined -fno-omit-frame-pointer -fno-pie' \
  -DCMAKE_EXE_LINKER_FLAGS='-fsanitize=address,undefined -no-pie'
cmake --build build/p0-sanitize --parallel 4
ASAN_OPTIONS=detect_leaks=1 UBSAN_OPTIONS=halt_on_error=1 \
  ctest --test-dir build/p0-sanitize --output-on-failure

source /opt/ros/jazzy/setup.bash
colcon --log-base log/p0-colcon-build build --base-paths src/encos_core \
  --packages-select encos_core --build-base build/p0-colcon \
  --install-base install/p0-colcon --cmake-args -DBUILD_TESTING=ON
colcon --log-base log/p0-colcon-test test --base-paths src/encos_core \
  --packages-select encos_core --build-base build/p0-colcon --install-base install/p0-colcon
colcon test-result --test-result-base build/p0-colcon --verbose
```

## 后续门槛

P1 的虚拟验证可以使用已通过的协议分支。进入 P1 前需用户审核。调试手册没有回复序列号或迟到时间上界。同一回复签名在无可靠上界的会话内禁止复用。P1 若验证高频同型问答，须给虚拟设备和传输明确设定、验证迟到上界，或建立可靠的会话隔离。这个边界不能从 MockTransport 推到真实驱动。

P3/P4 仍为 BLOCKED，直到厂商和现场确认该机型供电、接线、通信参数、抱闸能力、再生吸收、温度保护和超时动作。加速度配置编码、通信方式回显以及 Kt 头歧义继续隔离。当前停在 P0。
