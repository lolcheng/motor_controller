# 现场操作前检查（全项人工确认）

- [ ] 厂家针对具体型号/硬件/固件确认允许供电范围及过压阈值，解决72V与20–57V矛盾。
- [ ] 电源具备合适限流、保护与再生能量吸收；外壳固定，输出端空载，人员避开旋转区域。
- [ ] 独立硬件急停经过验证；确认失能、超时和制动真实行为；无自动重新使能。
- [ ] 针脚、极性、通信线、隔离与终端电阻正确；断电接线；适配器支持SocketCAN及当前模式。
- [ ] 仅连接一个电机；接口名/波特率/采样点/BRS与厂家配置匹配。
- [ ] P0–P2报告已审核；实际固件与协议兼容性确认；只读与运动授权分开。
- [ ] 现场负责人批准单项实验角度、速度、电流、力矩、温度、持续时间、通信超时与停止策略；设置软件和独立硬件保护。
- [ ] P3真实反馈已验证；记录日志路径；P4从低风险试验开始；任何异常立即停机并锁存，人工排查。

本清单不替代厂商指导或实验室安全规程。未确认不得发实机帧。
