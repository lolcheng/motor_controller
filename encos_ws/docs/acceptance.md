# P0–P4 验收门槛

| 阶段 | 核心验收 | 证据 |
|---|---|---|
| P0 | 所有已定义且无歧义的协议编码、解码、查询、配置及错误分支；争议项隔离 | 独立 golden vectors，边界、符号、非法值、长度、量化误差、事务单测；逐项覆盖表 |
| P1 | P0 回归、虚拟电机及真实 SocketCAN/vcan 问答，经典 CAN 和 FD+BRS 各测。验证丢帧、超时、乱序、重复、异常帧、断连和人工恢复 | 逐项独立报文向量、进程退出、ASan/UBSan、并发检查、Jazzy colcon。10/50/100/200/400/500/1000 Hz，400 Hz 各至少 60 秒，保留逐周期 CSV。不可执行时具体标记 BLOCKED。 |
| P2 | ROS 2 Jazzy Topic、Service、Action 与独立 C++ SocketCAN 控制线程。只在 vcan 验证，保留 P0 歧义隔离。 | 测试授权、抢占、取消、超时、锁存、配置读回和 rosbag/CSV 完整性。经典与 FD 分别记录 10/50/100/200/400 Hz 的 A–E 工况，主要 400 Hz 工况至少 60 秒。正常工况初步目标 396 Hz 有效反馈、无意外超时、无错配。 |
| P3 | 现场确认供电、接线、固件、急停后单电机只读通信 | 实机原始 TX/RX、实际ID、版本、范围、超时、状态查询结果；无运动命令 |
| P4 | 空载分模式受限控制、反馈闭环、超时与停止验证 | 人工审批记录，真实轨迹/电流/温度/故障/时间戳，实际频率、RTT p50/p95/p99/max、周期误差、丢帧率；逐项判定 |

P4先低频、再100/200/400Hz逐级提升，是否升级由实测和批准的实验限值决定。400Hz目标周期2.5ms；延迟/丢帧门槛由现场实验要求确定，不编造实测值。所有高风险配置命令以P0/P1覆盖为必要条件，实机仅独立批准后验证；不存在或不支持的功能标N/A或BLOCKED并保留证据。软件全部覆盖与硬件全部通过是不同结论。

P4实机先验证低风险位置控制、速度控制和混控；电流/力矩及制动/抱闸需独立安全条件，见 AGENTS。禁止直接测试手册额定/峰值。P4不涉及带载。

P1 的 vcan 性能单独记录已发送未匹配的回复比例、周期超期及跳过的周期。两种帧型的 400 Hz 验收列出实际频率和延迟分位，供审核评估。决策只适用于虚拟链路。进入 P2 前须审阅 [P1 阶段报告](reports/P1.md)。

P2 虚拟验收 PASS。A–E 共 50 个工况通过，400 Hz 有效反馈频率为 397.152–399.313 Hz，连续有效发送超过 60 秒，各工况未出现意外反馈超时。保留两轮未达标证据。P3 现场准入为 BLOCKED，需通过人工审核和现场准备清单。[P2 实际结果](reports/P2.md) · [现场准备清单](hardware_checklist.md)
