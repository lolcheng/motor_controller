# P2 开发提示词

请先重新阅读 AGENTS.md、两份原始手册及 docs/acceptance.md，并检查此前阶段报告。仅执行 P2。

目标：ROS 2 Jazzy完整软件链路。实现所有包 manifest/CMake、msg/srv/action、launch、配置、driver和实验工具；核心独立C++高频线程使用单调时钟，ROS回调仅交换目标及状态，写操作与运动互斥。支持类型化指令/状态、参数读写服务（默认禁止实机写）、授权/停止、实验action取消、rosbag2和CSV记录；记录真实采集/发布时刻及缺失字段。实现mock/vcan的端到端测试：查询、各模式、停止、过期、取消、故障锁存、配置保护；目标400Hz运行至少60秒，报告实际延迟、抖动、丢帧、队列溢出（不是硬件指标）。执行colcon build/test/test-result，更新README和P2报告。不得启动物理CAN。

最后列出修改文件、执行的命令和实际结果、未解决问题、下一阶段前置条件；停止，不自行进入后续阶段。
