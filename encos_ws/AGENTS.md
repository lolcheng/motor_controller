# Codex 工程约束（每阶段必读）

## 范围与来源
- 目标单电机 EC-A10825-P2-24H-B；Ubuntu 24.04、ROS 2 Jazzy、C++17、ament/colcon；原生 SocketCAN，支持经典 CAN 和 CAN FD+BRS。禁止将厂商私有协议当成 CANopen 或通用 MIT。
- 先逐页核对 docs/vendor 的两份 PDF，表格/位域须看原图；记录印刷页码、原始报文、推导及疑点。缺少 PDF 时停止协议实现并报告，不联网用其他版本替代。
- docs/protocol_coverage.md 是范围清单，不是权威编码规范。每条命令、每个反馈分支与协议疑点必须有对应测试及报告。保留未知/保留字段为不支持，不虚构启停命令。
- P0–P4 不涉及带载、峰值性能、机器人整机、ros2_control、系统辨识或修改固件。

## 架构及编码
- core 不依赖 ROS；Transport 抽象 + SocketCAN + MockTransport；独立协议编解码/事务/状态机，显式标准 ID、帧型、BRS、长度、字节序、位域、缩放和符号。使用固定宽度整数、显式序列化，float32 安全位转换，禁止 C++ 位域或结构体 memcpy 直接作为线协议。严格检查 NaN/Inf、越界、长度、错误帧、RTR、扩展帧及非法枚举；未知报文留原始日志，不能驱动状态机。
- 高层单位统一 rad、rad/s、Nm、A、°C；在协议边界处理度、rpm、量化、不同反馈精度。反馈相电流与估算力矩分开，标记有效性、来源与时间，不伪造母线电流或真力矩。类型 2/3 缺失量不可写成 0 或新鲜值。
- 上电先查询/核验实际 ID、固件/硬件版本、协议范围、Kt、补偿状态、超时、抱闸能力；范围未确认禁止混控及依赖该范围的反馈解释。型号额定值与编码范围、实际实验限幅必须分开。所有参数写入默认关闭，非运动指令也可能危险。
- 问答模式的回复匹配考虑同 ID、不同类型、查询码、特殊前缀、多帧 UUID、Kt 分组和无序/重复/丢失；不把本机 TX 回环当作真实反馈。单电机串行未完成事务；迟到帧不配给新事务；不得假定协议存在序列号。
- ROS 节点内部 C++ 控制线程直连 SocketCAN；ROS 发布物理量而非必须经原始 CAN Topic；原始帧 Topic 仅可选观测，禁止默认开放任意帧发送。控制线程使用单调时钟、绝对周期、有限等待、独立记录队列；避免日志、DDS、文件 IO 阻塞高频循环。记录命令生成、TX 调用/可用内核时间、RX 和 ROS 时间，区分主机接收与电机内部采样；统计实际频率、延迟分位、抖动、丢帧、队列溢出。
- ROS Topic: /encos/motor_command、/encos/motor_state、/encos/fault、/encos/communication_stats、/encos/control_sample，可选 /encos/raw_rx、raw_tx；标准 /joint_states（effort 如使用估计须明确）；查询/配置/授权用 service，有限时长实验用 action，支持取消；QoS 和命令有效期明确。统一只允许一个控制命令所有者。

## 实机安全硬约束
- 默认 mock/vcan0；物理接口启动默认禁止一切发送，包括查询，需操作员显式授权。只读模式仅白名单查询，运动模式另需独立人工授权；授权、故障复位、重连均不能自动触发运动。不得自动切换电机模式、改 ID、清零、写 Kt/PID/量化范围、关闭超时、释放抱闸。参数写入与运行互斥；现场人工确认后单项写入、读回核验及回退，通信模式切换需预案。
- 上电前必须确认厂家针对该型号的电压范围（72V vs 20–57V 矛盾）、针脚、接地/隔离、终端电阻、再生能量吸收、急停、固件/协议版本、CAN 超时后的动作、抱闸是否存在。未确认则 P3/P4 BLOCKED。严禁凭推断供电，严禁热插拔；电机外壳固定、输出端空载、人员远离旋转区。
- 软件状态机建议 DISCONNECTED/READ_ONLY/UNARMED/ARMED/RUNNING/STOPPING/FAULT；只有新鲜反馈、配置有效且人工授权后才能运动。硬件急停独立于电脑/ROS/CAN；停止策略必须由厂商确认并验证，零力矩不是抱闸，通信超时不保证安全保持。设置命令新鲜度/实验最长时长/机械角度、速度、相电流、估算力矩、温度、反馈超时、总线故障等保护。任何非有限数、超限、错误或反馈丢失进入经确认的安全停止并锁存；禁止自动恢复。
- 电流/力矩空载可能持续加速；仅在现场保护完备、厂商认可、速度与时长严格受限的短时小幅实验中验证，不做持续电流/力矩跟踪。不实机执行所有配置指令作为验收条件；无抱闸硬件时抱闸实机项标 N/A。制动模式须确认电源吸收与适用性。禁止峰值、堵转、热/过压故障注入等危险实机试验。
- 所有实际硬件操作由现场人员执行；Codex 自动测试仅 mock/vcan，不自动 sudo、配置真实接口、启动硬件节点、发实机帧或宣称实机通过。生成命令与检查流程供现场人员审核。
